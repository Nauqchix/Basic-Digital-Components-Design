## Basic Digital Components Design

This repository contains implementations of fundamental digital components used in digital system design. The project focuses on designing and simulating basic building blocks such as flip-flops, counters, registers, and other sequential or combinational circuits.

The goal of this repository is to practice RTL-based digital design and understand how basic hardware modules are implemented and tested.

### Key Topics
- Combinational Logic
- Sequential Logic
- Flip-Flops
- Digital Circuit Design
